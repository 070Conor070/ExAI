Run real SHAP analysis on this dataset with Python. All code below is in analysis.py — download it and follow the setup steps.

Quick start
# 1. Install dependencies
pip install pandas numpy scikit-learn shap matplotlib

# 2. Download the dataset from Kaggle (free account required)
#    https://www.kaggle.com/datasets/adilshamim8/student-performance-and-learning-style
#    Save as: student_data.csv  (same folder as analysis.py)

# 3. Run
python analysis.py
What analysis.py does
StepDescription
1. Load & cleanReads CSV, encodes categoricals, splits train/test
2. Train modelGradient Boosted Regressor predicting ExamScore
3. EvaluatePrints RMSE and R² on test set
4. SHAP globalBar plot of avg |SHAP| per feature (saves shap_global.png)
5. SHAP beeswarmFull summary plot showing direction of effect (saves shap_beeswarm.png)
6. Student explainForce plot for a single student — shows each feature's push up/down
7. TraverseCLI traversal — filter by grade, study hours, stress and print results
